# Contributing to OpenAPI Studio

Thank you for your interest in contributing to OpenAPI Studio.

OpenAPI Studio is being developed as an open-source project with an emphasis on understandable architecture, reliable testing, security, accessibility, and maintainability.

## Before You Start

Please read:

- `README.md` for project information and setup instructions.
- `SECURITY.md` for security-related concerns.
- `CODE_OF_CONDUCT.md` for community expectations.

For larger changes, please discuss the proposed direction in an issue before starting implementation. This helps avoid duplicated work and keeps contributions aligned with the project roadmap.

## Development Environment

The project currently uses:

- Node.js
- pnpm
- React
- TypeScript
- Vite
- ESLint
- Prettier
- Vitest
- React Testing Library
- jsdom

Install dependencies with:

```bash
pnpm install
```
